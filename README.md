## 🎯 핵심 목적 & 5초 브리핑 시스템

1. **오늘 저녁 5초 브리핑 카드 (Today Evening Briefing)**:
   - 퇴근길/저녁 시간에 자녀별 현재 일정, 남은 귀가 시간(실시간 카운트다운), 이동 방법(셔틀/도보/픽업), 저녁 식사 준비 여부(집밥/외부/간식)를 한눈에 파악.
   - 귀가 30분 전 깜빡이는(Pulsing) 긴급 알림 배지 및 귀가 시간 변경 강조.
2. **월간 가족 캘린더 (Monthly Family Calendar)**:
   - 한 달 전체를 달력 형태로 조망.
   - 구성원별 고유 시그니처 색상: **첫째(파란색 👦)**, **둘째(초록색 👧)**, **부모 일정(보라색 💼)**, **가족 공통(주황색 🏠)**.
   - 날짜 칸마다 대표 귀가 시간과 미완료 체크리스트 개수 직관적 표시.
   - 날짜 클릭 시 아래 주간 상세 일정이 해당 주로 부드럽게 이동.
3. **주간 상세 스케줄 (Weekly Detailed Schedule)**:
   - 월요일부터 일요일까지 7일간의 세부 동선.
   - 모바일: 보기 편한 세로 타임라인 카드 / 데스크톱: 한눈에 들어오는 7열 주간표 지원.
   - 출발 시간, 귀가 시간, 이동 수단, 담당 보호자, 식사 여부, 메모 상세 제공.
4. **자녀별 챙길 일 체크리스트 (Child Checklist)**:
   - 분류: `준비물`, `과제·학습`, `복약·건강`, `식사·간식`, `학원·활동`, `부모 확인`.
   - 별표(중요) 표시, 미완료 항목만 모아보기 필터, 달성률 게이지(%).
   - 모든 항목 완료 시 기분 좋은 축하 애니메이션(Confetti) 폭죽 효과.
   - **미완료 항목 내일로 넘기기(이월)** 원클릭 지원.
5. **충돌 및 겹침 사전 경고 (Conflict Detector)**:
   - 동일 보호자의 픽업 시간이 20분 이내로 중복되거나 부모 야근과 겹칠 경우 자동 경고 배너 표시.
6. **로컬 스토리지 & 오프라인 즉시 동작**:
   - 별도 서버 설치 없이 브라우저 내에서 완벽하게 동작하며 변경 사항이 자동 저장됩니다.
   - 현실적인 한국 가족 일정 샘플이 오늘 날짜 기준으로 자동 로드됩니다.

## 🚀 실행 방법 (Getting Started)

Node.js(v18 이상 권장)가 설치된 환경에서 터미널을 열고 다음 명령어를 실행합니다:

```bash
# 1. 의존성 패키지 설치 (최초 1회)
npm install

# 2. 로컬 개발 서버 실행
npm run dev
```

터미널에 표시되는 로컬 주소(예: `http://localhost:5173`)로 브라우저에 접속합니다.

### 프로덕션 빌드 및 미리보기
```bash
# 타입 체크 및 최적화 빌드
npm run build

# 빌드 결과물 미리보기
npm run preview
```

## 📋 샘플 일정 데이터 안내

실행 즉시 모든 기능을 체험할 수 있도록 오늘 날짜(`new Date()`)를 기준으로 다음과 같은 현실적인 가족 데이터가 사전 탑재되어 있습니다:

- **첫째 김은비 (파랑 👧)**:
  - 심화 수학 학원 (17:00 ~ 19:10 귀가) / 학원 셔틀 / 🍚 집밥 저녁 필요
  - 영어 회화, 과학 탐구 실험 동아리, 문법 심화반
  - 체크리스트: 은비 수학 학원 오답노트 & 계산기, 학교 보고서 출력, 비염 알러지 약 복용
- **둘째 김하율 (초록 🧒)**:
  - 태권도 승품 심사반 (16:30 ~ 18:30 귀가) / 나(아빠) 픽업 / 🍚 집밥 저녁 필요 (귀가 시간 변경 배지)
  - 피아노 레슨, 방과후 창의 미술 교실, 어린이 수영
  - 체크리스트: 하율이 도복 & 빨간 띠 챙기기, 귀가 후 운동화 신발장 정리, 어린이 유산균 섭취
- **나 & 아내 (보라 💼)**:
  - 나(아빠) 퇴근 및 하율이 픽업 (18:00 ~ 19:30)
  - 체크리스트: 은비 학교 현장체험학습 동의서 온라인 서명, 19:10 은비 귀가에 맞춘 저녁(된장찌개) 준비
- **우리 가족 (주황 🏠)**:
  - 주말 4인 가족 나들이 & 패밀리 레스토랑 외식

## 🔗 향후 Google Calendar 및 Notion 연동 확장 방법

대시보드 상단의 **[연동 안내]** 버튼을 누르면 실시간으로 파일 내보내기 및 코드 가이드를 확인할 수 있습니다.

### 1. Google Calendar 연동
- **방법 A (즉시 사용 가능한 .ics 내보내기)**:
  - 대시보드의 `Google 캘린더용 .ics 내보내기` 버튼을 클릭하면 표준 iCalendar 파일이 다운로드됩니다.
  - 구글 캘린더 웹에서 `설정 > 캘린더 추가 > 가져오기`를 통해 즉시 등록할 수 있습니다.
- **방법 B (Google Calendar API 양방향 동기화)**:
  - Google Cloud Console에서 OAuth 2.0 Client ID 발급.
  - `@googleapis/calendar` 클라이언트 라이브러리를 통해 가족 구성원별 캘린더 ID로 실시간 insert/update 연동.

### 2. Notion Database 연동
- Notion Developers에서 Private Integration Token 발급.
- 노션 페이지에 '우리 가족 스케줄' 및 '챙길 일' 데이터베이스 생성.
- `@notionhq/client`를 사용하여 일정 추가/체크리스트 완료 상태를 노션 데이터베이스 프로퍼티와 1:1 동기화.
